# 예선 규칙과 시간 계산

## 현재 재시험 일정: 사용자 전달 (2026-11-02)

- **2026-11-04 수요일 19:00~23:00 KST, 제한 4시간**을 기본값으로 반영했습니다. 플랫폼의 실제 시작 시각과 최신 안내가 우선합니다.
- 작업 뒤 구현 기반 서술형이 있으며 참가자가 직접 답합니다. 정확한 배분 분 수는 미확인입니다. config의 30분 서술형/구술과 생성 여유 10분은 원예선 안내를 바탕으로 한 **임시 보수적 여유**이며 현재 공식 배분으로 단정하지 않습니다. status에서 미확인 경고를 표시합니다.
- start의 `--work-minutes`, `--overall-end`, `--oral-minutes`, `--generation-reserve-minutes`로 확인된 현재 값을 세션 생성 때 지정할 수 있습니다. `--oral-minutes 0`은 서술형이 없다고 확인된 경우에만 사용합니다. 이미 만든 세션은 되돌리거나 초기화하지 않습니다.
- 기본 작업 종료 상한=min(실제 시작+240분,23:00). 임시 여유 30+10분을 사용하면 22:20까지 작업 확정,22:10 제출 시작을 권고합니다. 이 시각은 플랫폼 제한이 아니라 임시 계획입니다. 확인된 서술형 배분이 다르면 계산도 달라집니다.
- 실무 단계의 구현 설명 문서는 요청된 산출물입니다. 실제 제출 형식 안에서 작성·저장·제출하고 이후 서술형 답변은 참가자만 작성합니다.

## 아래는 원예선 안내의 역사적 기록

근거는 사용자가 제공한 `1_시험_필수확인사항_브리프.pdf`1쪽, `3_사전_체험_및_응시환경_상세_가이드.pdf`2~5쪽입니다. 이 문서는 핵심 조건을 요약한 것이며 최신 플랫폼/주최측 안내가 우선합니다. 원본PDF는 재배포하지 않습니다. 사용자는 본인이 만든 공개GitHub 저장소도 사용 가능하다고 주최측 확인 내용을 전달했습니다.

추가 확인: 사용자가 외부 자료는 **Git Clone으로 가져오는 것만 허용**된다고 전달했습니다. v1.1은 이 조건에 맞춰 추가 취득 경로를 Git Clone으로 한정하고 레지스트리 설치/URL 다운로드 기능을 제거했습니다. ZIP은 개인 PC에서 배포물을 준비하는 형식이며 시험 환경에 업로드하는 방식이 아닙니다.

## 원예선 시간 계산 예시 (아래 10월 31일 시각은 재시험에 적용하지 않음)

기본 `config/exam.json`의 질문 생성 여유10분은 키트의 보수적 추천값이며 공식 보장 시간이 아닙니다. 재시도에 더 오래 걸릴 수 있습니다.

```text
공식 작업 종료 추정 = min(실제 과제 시작 +180분, 전체 종료14:00)
권장 제출 확정 시각 = min(공식 작업 종료 추정, 전체 종료 -서술형30분 -질문 생성 여유10분)
권장 제출 시작 시각 = 권장 제출 확정 시각 -10분
```

10:00 시작: 작업 종료13:00, 권장 제출 시작12:50, 확정13:00.
12:50 시작: 작업 종료는14:00이지만, 서술형 여유를 고려한 권장 확정13:20/제출 시작13:10.
이미 권장 시각을 지났으면 여유가 부족하다고 표시합니다. 추가 시간을 만들거나 서술형 준비 지연을 해결했다고 주장하지 않습니다.

30분 남음: 선택 기능·대규모 리팩터링 중단을 권장합니다.10분 남음: 필수 파일·실행·저장·제출 흐름 우선. 이 단계 구분은 키트의 작업 전략입니다.

로컬 시간/단계 기록은 플랫폼 상태를 조회하지 않습니다. 참가자가 실제 시작/확정 시점을 알려줘야 하며 공식 화면 타이머가 우선합니다. 준비 중 권한이나 안내가 달라지면 이설정을 먼저 검토하세요.
