# React 과제일 때만 읽는 참고 지침

실제 프로젝트가 React 또는 Next.js를 사용할 때만 `upstream/vercel/skills/react-best-practices/SKILL.md`와 해당 문제에 필요한 `rules/` 파일을 읽습니다. 다른 스택을 React로 전환하는 근거가 아닙니다. 전체 `AGENTS.md`를 매번 읽거나 모든 성능 규칙을 일괄 적용하지 않습니다.

먼저 실제 필수 기능과 상태의 정확성을 확인합니다. 필요할 때 다음 항목을 살핍니다.

- props/state에서 계산 가능한 값을 별도 state와 Effect로 중복 관리하는지
- 독립된 요청을 불필요하게 순차 실행하는지, 늦은 응답이 최신 상태를 덮는지
- 서버·클라이언트 경계와 공유 가변 상태가 제공된 버전에 맞는지
- 로딩·빈 결과·실패 상태가 서로 구분되는지
- 실제로 큰 모듈이나 비싼 계산이 확인됐을 때만 로딩·렌더링을 최적화하는지

프로젝트의 React/Next 버전과 인터페이스가 우선입니다. 참고 문서의 최신 API를 확인 없이 복사하지 않습니다. SWR, better-all, LRU 캐시 등 추가 의존성을 설치하지 않습니다. 이미 제공된 기능 또는 기본 Promise/React 기능으로 해결합니다. 성능 수치는 원본의 설명이며 이 키트가 재현한 결과가 아닙니다.

Vercel 배포, 계정 연결, 웹 문서 다운로드, 브라우저 조작은 이 참고자료의 사용 과정에 포함하지 않습니다. 실제 화면은 참가자가 허용된 플랫폼 미리보기에서 확인합니다.
