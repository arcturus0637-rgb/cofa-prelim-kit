# v1.2 문제 해결과 품질 지침

## v1.4 범용 최적화 적용

버스 전용 스킬과 고정 정류장 검사기를 제거했습니다. `cofa-optimize`가 공개 최적화 스킬을 선택적으로 참고해 실제 모델·해법·최적성 근거를 구성하고, `cofa-opt-service`가 실제 입력부터 결과까지 서비스를 완성합니다. KKT·선형화·다목적·솔버 상태에 관한 원문의 과도한 일반화는 source-guide의 보정을 먼저 적용합니다. 범용 완성 풀이/서비스나 전역 최적해 보장은 포함하지 않습니다.

`cofa-explain`은 실무 단계에서 참가자가 요청한 실제 구현 설명 문서를 작성합니다. 기본명 IMPLEMENTATION.ko.md, 필수 제출 형식이 있으면 그 안에 통합합니다. 생성된 템플릿이 아니라 실제 코드/알고리즘/검증/한계가 담긴 문서를 확인·저장·제출합니다. 후속 서술형 문항을 만들거나 답하지 않습니다.

기본 일정은 사용자 전달 재시험 2026-11-04 19:00~23:00, 240분으로 갱신했습니다. 서술형/구술 배분은 정확한 분 수가 미확인이어서 임시 여유와 확인된 값을 구분합니다. 실제 플랫폼 제한과 현재 안내가 우선입니다.

새 스킬은 `cofa-reason`, `cofa-test-design` 두 개입니다. 기존 디버깅·리뷰·검증·단순화와 역할을 연결하고 실제 필요가 있을 때만 읽습니다. 이 파일은 대회 규칙을 추가하거나 모델의 추론 능력 향상을 보장하지 않습니다.

## 문제를 분석할 때

`cofa-reason`은 요구사항을 완료 조건으로 바꾸고 사실·가정·미정 정책을 구분합니다. 기존 입력/처리/저장/출력 경로를 먼저 읽고, 결과를 바꾸는 불확실성만 작은 실험이나 허용된 업무 질의로 해소합니다. 쉬운 수정은 바로 좁혀 검증합니다. 긴 사고 과정, 정해진 가설 개수, 설계 승인 절차를 강제하지 않습니다.

## 테스트를 설계할 때

`cofa-test-design`은 실제 구현을 호출하는 검사와 독립적인 기대값을 고릅니다. 요구사항에 맞는 정상·경계·실패 사례, 필요하면 유효한 보존/변환 성질을 검사합니다. 멱등성 하나를 통과해도 기대한 정규화가 구현됐다고 단정하지 않습니다. 중복 행 보존은 집합 비교가 아니라 개수까지 확인해야 합니다.

속성 검사 라이브러리가 없으면 기존 실행기와 표준 라이브러리로 제한된 사례를 확인합니다. 이를 모든 입력에 대한 증명이나 Hypothesis의 자동 축소와 동등한 기능으로 표시하지 않습니다. 미정인 결측값/정밀도/자격 조건은 임의로 정하지 않습니다. 실제 UI는 참가자가 플랫폼에서 수동 확인합니다.

원본의 일부 일반화에는 어댑터에서 보정을 명시했습니다. 사양에서 독립적으로 얻은 기대값은 구현과 식이 닮았다는 이유만으로 무효가 되지 않습니다. 덧셈의 교환/결합 법칙만 검사하면 XOR도 통과할 수 있습니다. 속성의 보편적인 강도 순위를 가정하지 않고 상호 보완적인 요구사항 검사를 고릅니다. 필터 소진 시의 결과는 실제 실행기의 출력/종료 상태를 확인합니다. 원본 스냅샷은 수정하지 않았습니다.

## 실패를 만났을 때

`cofa-debug`에 시도/관찰/배제된 설명/다음 실험의 짧은 기록을 추가했습니다. 같은 영역의 비개선 시도가 반복되면 전제를 재검토하고 입력·호출부·설정·저장·실행 환경으로 조사를 전환합니다. 새 근거 없이 같은 수정을 반복하지 않습니다. 잘못 말한 사실은 근거와 함께 정정합니다. 마감이 가까우면 검증된 핵심 동작을 보존하면서 작은 대안을 검토합니다.

`cofa-verify`는 구현됨, 실행해 관찰됨, 미확인/막힘을 구분합니다. 테스트 수집 실패나 0건 실행은 동작 통과가 아닙니다. 성공 샘플로 실패를 가리거나 기대값을 약화하지 않습니다. 원래 증상과 실제 필수 동작을 다시 확인합니다.

## React 조건부 적용

프로젝트가 실제 React/Next.js일 때만 [React 참고](REACT.ko.md)를 읽습니다. Vercel의 지침은 제공 버전과 기존 구조에 맞게 선택하며 새로운 의존성·호스팅·MCP를 설치하지 않습니다. 필수 동작을 먼저 완성하고 필요가 확인된 성능 문제를 다룹니다.

## 검증 범위

실제 시험 문제와 무관한 가상 사례로 기본 판단과 새 지침을 비교합니다. 기본 판단이 이미 적절한 사례는 개선으로 집계하지 않습니다. 문법/등록/무결성 검사와 행동 점검은 다른 검증입니다. 실제 대회 런타임·UI·채점 성적은 미확인입니다. 실행 기록은 [검증 문서](VALIDATION.ko.md)에 남깁니다.
